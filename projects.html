Systems Analysis & Design 06

UniTicket: Multi-Service Booking System

A group systems analysis and design project focused on planning one platform where users could search and book flights, trains, and event tickets.

Requirements Analysis DFD Diagrams UML Data Dictionary Wireframes System Modeling
Project Details

What we worked on

As a group, we planned UniTicket from the early problem and requirements stage through system and interface design. The project looked at stakeholders, functional and non-functional requirements, feasibility, risks, system processes, and the data needed to support the booking platform.

The report also included context and Level-0 data flow diagrams, use cases, a data dictionary, UML models, wireframes, forms, and dashboard designs.

What I learned

This project helped me understand how much planning happens before a system is actually developed. It made me think about users, requirements, data, processes, security, and interface design as parts of the same system instead of treating each one separately.

Working through the different phases also gave me more experience explaining technical decisions and working with a group to build one larger system design.
